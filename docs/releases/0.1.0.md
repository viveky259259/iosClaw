# iosClaw 0.1.0 public beta

This is the first direct-download beta of iosClaw for macOS 15 and later.

## Highlights

- Inspect an iPhone Mirroring or iOS Simulator screen with local capture and
  OCR.
- Resolve actions from current semantic evidence instead of replaying saved
  screen coordinates.
- Record verified action flows and replay them with fresh state checks.
- Run compiled local flows without returning to an agent between every step.
- Keep audit, learned-context, recording, and QA data encrypted on the Mac.
- Require explicit approval for sensitive external effects and fail closed when
  the visible app or state cannot be verified.

## Initial limitations

- The Mac must run macOS 15 or later.
- Screen Recording is required for inspection. Accessibility is required only
  for verified input through iPhone Mirroring.
- Apple may ask for one final permission approval when migrating from an older
  Apple Development build to this Developer ID release.
- The bundled WhatsApp Business messaging flow prepares a draft and stops
  before Send.
- QA Mode is a developer preview. The iPhone companion is optional and is not
  included in this Mac release.

## Integrity

The published DMG is Developer ID-signed, Apple-notarized, stapled, and
accompanied by a SHA-256 checksum. Do not distribute or install artifacts whose
filename contains `UNNOTARIZED`.
